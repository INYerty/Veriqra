## Task pagination

`GET /api/projects/{projectId}/tasks` now accepts `page`, `pageSize`, `status`, `teamId`, and `assigneeId`, returning the existing `Page` shape (`items`, `total`, `page`, `pageSize`). Defaults are page 1 and size 25; the server rejects invalid values and caps page size at 100. SQL applies project and authorization predicates plus filters to both `COUNT(*)` and `LIMIT/OFFSET` queries, ordered by unique `id DESC`. It does not fetch all tasks and slice in Java. The existing unpaged DAO method remains only for an internal business check, not the list API.
